# SQL Learning

A collection of SQL and Database Management Systems assignments completed in Database Management Systems (CSC1213) course unit during Bachelor of Computer Science degree at the University of Ruhuna.

## Contents

This repository contains my work related to:

* Database creation and management
* Table creation and modification
* Data manipulation
* Data retrieval
* Filtering and sorting
* Aggregate functions
* Grouping
* Joins
* Subqueries

## Repository Structure

The `.sql` dump files are included as complete database backups that can be used to recreate the databases used in the assignments.
